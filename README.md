# changtee-website

Website and admin workspace for **ช่างตี๋ ผ้าม่าน**.

- Next.js App Router, Tailwind CSS, and Vercel
- Dedicated Supabase project `pfwygxzwlteqjnnwiwmb`, schema `changtee_web`
- Public site, quotation/estimate lead intake, and `/admin` in one project

## Quick start

```bash
cd "C:\Users\Admin\WP GROUP\changtee-website"
cp .env.example .env.local
npm install
npm run dev
```

Open `http://localhost:3000`; admin is at `http://localhost:3000/admin`.

## Scripts

- `npm run dev` — development server
- `npm run typecheck` — TypeScript validation
- `npm run lint` — ESLint
- `npm run build` — production build
