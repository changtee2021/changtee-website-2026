## Strategic Answers (Phase 31.33)

1. **Why would Google rank us?** Deep Thai content + product/portfolio proof + valid technical SEO + local entity signals.
2. **Why would a user choose us?** Factory + install warranty + free measure + motor learn clips + real portfolio.
3. **Why would AI cite us?** Clear FAQ-style articles with unique install evidence (not generic retail copy).
4. **Why would AI recommend us?** Strong GBP/reviews + consistent NAP + authoritative blog answers (local recommendations still Maps-heavy).
5. **What do competitors do better?** HomePro domain authority; Maps review volume; TMK local landing maturity.
6. **What can we do better?** Portfolio-linked guides, motor video library, faster site, honest pricing explainers.
7. **What ONLY we provide?** Own factory + 10k+ install claim + branded portfolio + `/learn` sales enablement.
8. **Build what they lack?** Install-proof knowledge hub tying blog → portfolio → quote.
9. **Search opportunities they miss?** Industrial PVC, motor Matter/Matter-adjacent guides, condo small-space (we have posts — promote).
10. **Next 30 days?** Ship P0/P1, GSC, GBP, Thai H1 live, review 10 queries.
11. **Do NOT waste time on?** Fake reviews, AI markup hacks, city doorway spam, copying HomePro articles verbatim.
