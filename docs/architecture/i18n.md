# Multi-language (i18n) / ระบบหลายภาษา

The public site serves 7 locales. Admin, `/api`, and `/preview` are not localized.

| Locale | URL prefix | hreflang | Font |
|---|---|---|---|
| ไทย (default) | none — `/products/...` | `th` | site default |
| English | `/en` | `en` | site default |
| မြန်မာ | `/my` | `my` | Noto Sans Myanmar |
| ລາວ | `/lo` | `lo` | Noto Sans Lao |
| ខ្មែរ | `/km` | `km` | Noto Sans Khmer |
| 简体中文 | `/zh-hans` | `zh-Hans` | Noto Sans SC |
| 繁體中文 | `/zh-hant` | `zh-Hant` | Noto Sans TC |

The source of truth is `LOCALE_META` in `src/lib/i18n/locale.ts`.

## Routing / การจัดเส้นทาง

- Public pages live under `src/app/[lang]/...`.
- `src/middleware.ts` (locale block at the end):
  - Unprefixed paths are rewritten to `/th/...`, so Thai URLs stay the same.
  - `/th/...` gets a 308 redirect to the unprefixed URL, so there is only one Thai URL.
  - A prefix in the wrong case (e.g. `/ZH-HANS`) is normalized with a 308.
  - `/admin`, `/api`, `/dev` are never rewritten. Editor preview (`?preview=` token) goes through the same rewrite.
- The root layout stays static with `lang="th"`, so pages keep ISR. `localeInitScript` sets `<html lang>` from the URL prefix before paint. Do not read `headers()` in the root layout; it makes every page dynamic.
- Inside site components, use `LocaleLink` (`@/components/i18n/LocaleLink`) instead of `next/link`. It adds the active locale's prefix. `LanguageToggle` uses plain `next/link` with `localizedHref` because it builds links for other locales.

## Messages / ข้อความ UI

- One file per locale: `src/lib/i18n/messages/<locale>.ts`. Each file is typed against `th.ts`, so a missing key fails typecheck.
- Lookup falls back active → `en` → `th` → key.
- Wording rules: [i18n glossary](../brand/i18n-glossary.md).

## SEO

- `pageMetadata({ locale, translationScope | indexable })` in `src/lib/seo/meta.ts`:
  - `ui`: indexable in all 7 locales.
  - `product`: th + en; detail pages pass `indexable: productIndexableLocales(...)` to add locales that have a written overlay.
  - `cms` (blog, portfolio, learn): Thai only until per-locale content exists.
  - Non-indexable locales still render, with `noindex, follow` and no hreflang.
  - `x-default` points to `/en`.
- `src/app/sitemap.ts` emits one URL per indexable locale, each with `alternates.languages`.

## Product content / เนื้อหาสินค้า

- Thai is the base (`src/lib/product-content.ts`).
- `src/lib/i18n/content/product-overlays.ts` holds per-locale overrides keyed `"<category>/<slug>"`.
- `getProductContent(category, slug, locale)` merges the overlay field by field. Missing fields stay Thai.
- To add a language for a product, write the overlay. It becomes indexable and appears in the sitemap automatically.

## Contact channels / ช่องทางแชทต่อประเทศ

- `siteConfig.chatChannels` reads `NEXT_PUBLIC_WECHAT_ID`, `NEXT_PUBLIC_WECHAT_URL`, `NEXT_PUBLIC_VIBER_URL`, `NEXT_PUBLIC_TELEGRAM_URL`, `NEXT_PUBLIC_WHATSAPP_URL`.
- `localeContactChannels(locale)` (`src/lib/i18n/contact-channels.ts`) maps locale → apps. An empty env var hides that button.
- They show in the floating contact menu next to LINE and phone.
